# Sweden Driving Theory MCP — v1.1.0

Remote read-only MCP server for public Swedish Category B driving-theory content in English from EngelskaKorkort.se.

## Endpoints

- MCP: `/mcp`
- Health: `/health`
- OpenAI domain verification: `/.well-known/openai-apps-challenge`

## Tools

- `search_theory`
- `get_theory_page`
- `get_membership_plans`
- `get_free_theory_test`

All tools are explicitly annotated as:

- `readOnlyHint = true`
- `destructiveHint = false`
- `openWorldHint = true`
- `idempotentHint = true`

## Required environment variables

### Production

`ENGELSKAKORKORT_API_BASE`

```text
https://engelskakorkort.se/wp-json/ek-chatgpt/v1
```

`MCP_ALLOWED_HOSTS`

```text
sweden-driving-theory-mcp.onrender.com,sweden-driving-theory-mcp.onrender.com:*
```

### During OpenAI domain verification

Set `OPENAI_APPS_CHALLENGE` to the exact token generated by the OpenAI submission portal. The challenge endpoint returns only that token as plain text.

Do not set `MCP_ALLOWED_ORIGINS` unless a browser client requires it. This plugin has no custom UI.

## Render

Build command:

```text
pip install -r requirements.txt
```

Start command:

```text
python server.py
```
